## 3. 测试策略

### 3.1 测试层级

| 层级 | 工具 | 覆盖目标 |
|---|---|---|
| 单元测试 | JUnit 5 + Mockito | Domain Service 核心逻辑 |
| 集成测试 | SpringBootTest + MockMvc | Application Service 编排、REST API |
| 接口测试 | Postman / REST Client | 端到端接口验证 |
| 前端组件测试 | Vitest | Vue 组件逻辑 |
| E2E 测试 | Cypress / Playwright | 前端端到端 |

### 3.2 执行顺序

1. 冒烟测试（P0）
2. 主流程测试（P1）
3. 异常流测试（P1-P2）
4. 边界值测试（P2-P3）
