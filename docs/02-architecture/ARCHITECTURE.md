## 4. 分层与依赖

### 4.1 分层架构

```
interfaces → application → domain ← infrastructure
```

### 4.2 依赖规则

- `interfaces` 只做入参校验、DTO 转换、调用应用服务
- `application` 负责业务编排，不直接持久化
- `domain` 承载业务规则，不依赖外层
- `infrastructure` 实现仓储、缓存、外部适配
