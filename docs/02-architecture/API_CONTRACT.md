## 全局约定

### Base URL

```
/api/v1
```

### 统一返回体

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 业务状态码，0=成功 |
| message | string | 提示信息 |
| data | object/array/null | 业务数据 |

### 统一错误码

| 错误码 | HTTP 状态码 | 说明 |
|---|---|---|
| 0 | 200 | 成功 |
| 40001 | 400 | 参数校验失败 |
| 40101 | 401 | 未认证或 Token 过期 |
| 40301 | 403 | 无权限 |
| 40401 | 404 | 资源不存在 |
| 40901 | 409 | 资源冲突（重复创建等） |
| 50001 | 500 | 系统内部异常 |

### 认证方式

```
Authorization: Bearer <token>
```

### 分页请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| pageNum | int | 否 | 1 | 页码，从 1 开始 |
| pageSize | int | 否 | 20 | 每页条数，最大 100 |

### 分页响应结构

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 100,
    "pages": 5,
    "list": []
  }
}
```
