## 目标

定义所有 REST 接口的请求、响应、错误码、鉴权、幂等性和分页规则，作为前后端联调与测试依据。

## 范围

- 在范围内：接口编号、路径、参数、响应、错误、鉴权和约束
- 不在范围内：数据库实现细节

## 1. 全局约定

### 1.1 Base URL

```text
外部接口：/api/v1
内部接口：/internal/v1
```

### 1.2 统一返回体

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 业务状态码，0 表示成功 |
| message | string | 提示信息 |
| data | object/array/null | 业务数据 |

### 1.3 认证方式

```text
Authorization: Bearer <token>
```

### 1.4 分页约定

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| pageNum | int | 否 | 1 | 页码，从 1 开始 |
| pageSize | int | 否 | 20 | 每页条数，最大 100 |

## 2. 统一错误码

| 错误码 | HTTP 状态码 | 说明 |
|---|---|---|
| 0 | 200 | 成功 |
| 40001 | 400 | 参数校验失败 |
| 40101 | 401 | 未认证或 Token 失效 |
| 40301 | 403 | 无权限 |
| 40401 | 404 | 资源不存在 |
| 40901 | 409 | 资源冲突 |
| 42901 | 429 | 请求过于频繁 |
| 50001 | 500 | 系统内部异常 |

> 错误码与多语言文案需对应 `resources/error/error-codes.properties`、`error-messages_zh_CN.properties`、`error-messages_en_US.properties`。
