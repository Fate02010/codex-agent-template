## 目标

为当前版本建立可执行、可追溯、可自动映射到测试代码的测试用例基线。

## 范围

- 在范围内：当前版本功能、受影响回归、关键异常和边界场景
- 不在范围内：无业务价值的重复性低效用例

## 3. TC 与测试代码绑定规则

- JUnit 5：`@DisplayName("TC-XXX-001: 标题")`
- Vitest：`it("TC-XXX-001: 标题", () => {})`
- 一个测试方法只对应一个 TC 编号
- 回归测试可在方法名追加 `_r1`、`_r2`
