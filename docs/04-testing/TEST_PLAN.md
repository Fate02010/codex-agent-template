## 3. 测试策略

### 3.1 测试层级

| 层级 | 工具/方式 | 覆盖目标 |
|---|---|---|
| 单元测试 | JUnit 5 / Vitest | 业务规则与组件逻辑 |
| 集成测试 | SpringBootTest / MockMvc | 编排、持久化、接口层 |
| 接口测试 | REST Client / Postman / 自动化脚本 | API 契约与流程 |
| E2E 测试 | Cypress / Playwright | 关键端到端场景 |

### 3.2 执行顺序

1. 冒烟测试（P0）
2. 主流程测试（P1）
3. 异常流测试（P1-P2）
4. 边界与回归测试（P2-P3）
