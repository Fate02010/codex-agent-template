## 目标

## 范围

- 在范围内：共享页面结构、字段展示、交互行为、信息层级、权限差异
- 不在范围内：display / acceptance 差异策略、生产级代码实现与真实接口联调

### 后台管理默认交互约定

- 后台管理列表页默认必须包含分页组件，不得仅以滚动加载替代。
- 后台管理“新建 / 编辑”默认必须采用弹窗交互。
- 若采用抽屉或独立页，必须在本文件和 `PAGE_FLOW.md` 中显式写明交互载体与依据。
- 若列表页不分页，必须在本文件中显式写明业务原因与例外说明。

## 异常与边界

- 所有【设计推断】必须显式标记。
- 关键页面缺失时不得进入 `dev-implement`。
- display / acceptance 差异不得直接混写成共享必选项。
- 后台管理页面必须消费 `BACKOFFICE_UI_SPEC.md` 的 `BO-RULE-001~008`。
- 后台管理列表页若缺分页策略声明，不得进入 `prototype-build`。
- 后台管理新建 / 编辑若缺交互载体声明，默认按弹窗处理。
