# 内部验收原型说明

## 文档信息

- 文档类型：模板（首次执行 Skill 后覆盖）
- 生成 Skill：`ui-design-spec`
- 上游输入：`UI_DESIGN_SPEC.md`、`PAGE_FLOW.md`、`STATE_MATRIX.md`、`SCREEN_INVENTORY.md`
- 版本：v0.0
- 日期：—
- 状态：模板 → 草稿 → 已冻结

## 目标

定义 acceptance 原型的验收策略，保证状态覆盖、结构完整、关键字段可核对、门禁可消费。

## 范围

- 在范围内：状态显式要求、关键字段核对、验收辅助信息、门禁检查点
- 不在范围内：对外展示叙事优化、真实接口联调

## 异常与边界

- acceptance 是 `prototype-check` 的主门禁对象。
- 关键状态、关键字段和关键流程不得省略。
- 所有【待确认】项必须说明对门禁结论的影响。
